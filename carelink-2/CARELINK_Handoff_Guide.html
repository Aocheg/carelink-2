CARELINK 1.0 User Guide

Independent clinical care coordination application.

Start

  1. Install Python 3.12+ and dependencies with pip install -e '.[dev]'.
  2. Copy .env.example to .env.
  3. Run python -m app.database.init_db --demo for a demo environment, or python -m app.database.init_db and create the first administrator from the browser.
  4. Run uvicorn app.main:app --reload.
  5. Open http://127.0.0.1:8000/.

Demo accounts

admin / Admin123! · doctor / Doctor123! · nurse / Nurse123! · lab / Lab12345!

Workflow

Foundation → Patient → Admission → Vitals/Medication → Investigations → Doctor Review/Orders → Handover → Alerts → Discharge.

Security

Passwords use scrypt hashing and API access uses short-lived signed bearer tokens. Change demo credentials and configure a strong CARELINK_SECRET_KEY before shared use.

Important boundary

This is a working development/demo clinical information system. Real clinical deployment requires formal clinical governance, privacy/security review, migrations, backups, monitoring, TLS, and jurisdiction-appropriate regulatory review.
